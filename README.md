# ScrubZero for Mac

[ScrubZero](https://getscrubzero.com/) is a Mac menu bar app that swaps names, birth dates, phone numbers and record numbers for placeholders before you paste into Claude, ChatGPT and other AI apps.

This repo holds release downloads and the update feed. The source is not in this repo.

Download the latest DMG from [getscrubzero.com](https://getscrubzero.com/) or from Releases. The app checks this feed for updates once a day. Help: [getscrubzero.com/help](https://getscrubzero.com/help/).
